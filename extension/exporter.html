Quip to Markdown, read-only

Copies your Quip folders and documents into a folder (or one .zip file) on this computer as Markdown files, including calendars, Kanban boards, project trackers and spreadsheets.

Read-only. This tool only asks Quip to read things. It cannot create, edit or delete a Quip document, and it never deletes files from your target folder.

1 Connect to Quip

Create a personal access token at quip.com/dev/token while signed in, and paste it here. It is only ever sent to Quip.

Optional: preview one document

Paste the address of a Quip document to see what it becomes. Nothing is saved, and a preview leaves out images and attachments (a full export saves them). Needs the connection above; no folder.

2 Choose where to save

Quip's folder structure is recreated inside it. A new, empty folder or an Obsidian vault works well.
